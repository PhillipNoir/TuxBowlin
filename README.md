## Overview
TuxBowlin is an open-source C++ utility currently in early development. It is designed to bridge the gap between Rockstar's RAGE engine and modern Linux compatibility layers (Proton/Wine). By automating the deployment of essential community fixes, it aims to deliver a stable and high-performance experience out of the box.

## Planned Features
* **FusionFix Integration:** Automated extraction and placement of the latest PC port fixes.
* **Proton Environment Automation:** Generation of a custom Bash wrapper for critical variables (e.g., `WINEDLLOVERRIDES`).
* **Mjolnir_IV Integration:** Automated download and placement of GTA IV CPU Performance Fix for audio bugs.
